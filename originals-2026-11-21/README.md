# Widget files as they were on 21-Nov-2026, before the redesign

A frozen copy, kept so the old look stays reachable even if the files in the
repo root are ever renamed or tidied up.

The redesign does not overwrite anything. Each redesigned widget went live under
a NEW filename, so every file in the root is still the one it always was. This
folder is a second belt on top of that.

To put an old screen back: Zoho Creator -> INSPT app -> Settings -> Widgets ->
pick the widget -> set Index file to the old filename -> Save.

Static mockups of the new look live in `../design-2026-11-21/`.
